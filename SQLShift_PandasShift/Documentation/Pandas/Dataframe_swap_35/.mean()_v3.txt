OPERATOR: .mean()

DESCRIPTION:
The .mean() function is used to calculate the total sum of values within a numeric column.
The .mean() function ignores NaN values in the column.


SYNTAX:
table_name.sum('column_name').mean()


EXAMPLE WITH SAMPLE TABLE AND SAMPLE CODE:
OrderDetails = [['OrderDetailID', 'OrderID', 'ProductID', 'Quantity'], ['1', '10248', '11', '12'], ['2', '10248', '42', '10'], ['3', '10248', '72', '5'], ['4', '10249', '14', '9'], ['5', '10249', '51', '40']]
--- Sample Code 1 ---
Sample Code Description:
Use .mean() with Quantity Column. The following Pandas Code returns the sum of the Quantity field in the "OrderDetails" table:
Sample Pandas Code:
OrderDetails.sum('Quantity').mean()
